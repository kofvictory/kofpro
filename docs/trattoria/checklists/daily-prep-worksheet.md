# ランチ／ディナー 工程表(日次段取りシート)

**Baker's Dozen** ／ 書き込み式ワークシート（A4 1枚・ランチ/ディナー兼用）

毎日の段取りを1枚で回すためのシート。印刷して記入、またはラミネートしてマーカー運用。
レイアウト原本: `daily-prep-worksheet.print.html` ／ 配布用: `daily-prep-worksheet.pdf`

## 構成ゾーン

- **ヘッダー**: 日付・曜日・区分（□ランチ／□ディナー）・天気
- **仕込み 割り振り**: 担当①②③の3列（氏名欄＋記入行 各8行・行間広め）
- **発注**（2列・業者・数量）／ **当日買い物**（1列・店・品目）: 3分割（発注=2/3幅）
- **掃除・その他タスク**（2列・チェック付き）／ **アイデア・メモ**: 同じ行で3分割（掃除=2/3幅）

## 使い方メモ

- 区分のチェックで、同じ用紙をランチ／ディナーどちらにも使用。
- 仕込みは担当ごとに割り振り、終わった行を消し込み。
- 掃除・その他は毎日変わる臨時タスクを記入してチェック（定常の開店/閉店作業は
  `lunch-open-checklist` / `dinner-close-checklist` を併用）。
