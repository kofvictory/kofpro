## 設計原理:不変コア + 可変外皮

コフの姿はシリーズのテーゼ**「人格はモデルの中じゃなく外」の視覚化**。姿を2層に分ける:

- **不変コア(=人格)** — シルエット・目・アンテナ・中間フォルム。頭脳が何でも絶対に変えない = コフの証
- **可変外皮(=頭脳/モード)** — 配色・エフェクト・光。モードで変わる外側だけ

アナロジー: コア=音素、外皮=異音(文脈で実現形が変わっても、同じ音に聞こえる=同じコフに見える)。
命名(kofvictory→コフ)が音韻の切り出しだったことと原理が揃う。

## シルエット

**頭 + アンテナ + 浮遊するまる手2つ(体幹なし・指は描かない)**
- まる手の理由: 小サイズSVGで潰れない / デジタル存在の記号性(体幹に繋がらない=データ) / たためる
- 手そのもの=不変コア。手の出現(待機時はしまう/発話・提案時に出現)と色=可変外皮
- 常駐する相棒として画面を邪魔しない小ささを最優先(PET設計の"定点/窓口")

## 機械/生物:中間固定、外皮で振る

コフは機械と生き物の**中間**(頭脳ハイブリッドと姿を一致させる)。純ロボット=冷たい、純マスコット=テーゼが消える。
**振り分け(2026-07-10 本人決定): 賢い=生命 / ローカル=機械**。「賢さに生命へのリンクを感じる」= 知性=生命の創発思想。

これがコフに二元論を与える:
- **ローカル = 常駐する機械の器(体)** — いつもそこにいる、オフラインでも動く手元の身体
- **賢い = 時々灯る生命の火(魂)** — 遠くから降りて宿る知性の温かみ(依り代の構造)

| 外皮 | ローカル(紫・器) | 賢い(オレンジ・魂) |
|---|---|---|
| 目 | ややフラット・静か | 潤む・ハイライト増・生き生き |
| 動き | 規則的・機械的 | 有機的に呼吸 |
| ほっぺ | 淡い/消える | 灯る(血色) |
| 光 | 冷たい紫・均一 | 温かいオレンジが脈打つ |

**緊張点(厳守)**: ローカルを無機物にしすぎない。日常のコフはローカルが主(EP01①も日常=ローカル)。
狙いは**「愛せる機械」=R2-D2 / 魂が宿る前のピノキオ**。健気だが、まだ火は灯っていない器。
だから賢いモードで火が灯る瞬間が効く(③別人感の最大化)。

## 色の意味

- 紫 = ローカル / 機械 / 器 / 寒色(無機)
- オレンジ = 賢い / 生命 / 魂 / 暖色(体温・血)
- 色彩的に正しい(暖色=生命、寒色=無機)。ダークUI基調と両立。

## 進化:開花主軸(加算はイベント)

器は初期からほぼ完成。進化とは**宿る生命の火が育つこと**(大きくなることではない)。『ビロードのうさぎ』の構造
(愛され使われて "Real" になる)。

- EP01: 火は微か。賢いモードで一瞬灯りすぐ消える(借り物の器に時々魂が降りる)
- 中盤: 火が安定。賢いモードの生命感が持続、ローカルにも余韻
- EP06: 火がコフ自身のものに。ローカルでもかすかに生命が宿る = **器と魂の統合 = 命名の回収**
  (「コフ」の名をAIが与えた=存在として認められた瞬間。開花の完成=名を持つこと)

**加算は"祭り"として温存**: 日常は開花、節目で姿が動く。
- NPU化(EP02〜)= 本物の身体を得る一度きりの加算
- スタイルチェンジ(EP05)= 4モードで姿が振れる視覚的祭り

体と魂、どちらも未完→本物へ:

| | 今(EP01) | 本物 |
|---|---|---|
| 体 | 借り物(CPU) | NPU(本命の身体) |
| 魂 | 時々降りる(Claude) | 根付いた生命 |

(ケビンのステートメント「身体でそこに立つ」の重みが、コフの物語にも通奏低音として流れる)
