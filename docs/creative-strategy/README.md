# クリエイティブ戦略プロンプト集

店(トラットリア「ベイカーズダズン」店長+併設菓子店 Baton)と並行して「YouTube 3ライン・マネタイズ・写真プロジェクト」を進めるための、
AI(Claude Opus など)にそのまま貼って使えるプロンプトひな型と、ロードマップ構築フレームワークの集約。

## 前提: コンテキストの2層構造

すべてのひな型は、会話の冒頭に次の2つを貼る前提で書かれている。

- **[ペルソナ]** = リポジトリ直下 [CLAUDE.md](../../CLAUDE.md) の「オーナーコンテキスト」節(人物像・プロジェクト・作業スタイル。ほぼ不変)
- **[スナップショット]** = [01-prompt-guide.md](01-prompt-guide.md) ひな型Aを埋めたもの(今の数字・フェーズ。月1更新)

Claude Code のセッションでは CLAUDE.md が自動で読み込まれるため [スナップショット] だけ貼ればよい。
claude.ai(Opus)での戦略相談では両方を貼る。

## 使い方(3ステップ)

1. **スナップショットを最新にする** — [00-snapshot.md](00-snapshot.md) を確認し、古ければ更新(月次レビューのたびに上書き。ひな型は01のA)。
2. **目的のひな型をコピーする** — 各ファイルのコードブロックをコピーし、`{{...}}` を埋めて Opus に貼る。埋められない項目は「未定」と書けば AI が質問してくる。
3. **一往復で終わらせない** — 「骨子→合意→本文」の2段階と、01の反復パターン(深掘り/攻撃/圧縮)で磨き込む。会話の成果は必ず「圧縮」で持ち出して保存する。

## おすすめの進行順

- **初回セットアップ**: スナップショット作成 → 02-1でライン優先順位を決定 → 05-1で12週ロードマップ生成 → 第1週のタスクを LifeLog に登録
- **毎週の運用**: 05-2 週次レビュー → 02-4/02-5 で制作 → 思いつきは LifeLog の Inbox へ
- **毎月**: 05-3 月次レビュー + スナップショット更新(+ 02-7 アナリティクス診断)
- **クールごと**: 05-4 総括 → 03-1 収益源の再評価 → 05-1 で次クール設計

## 記法の約束

- `{{...}}` = 自分の情報に置き換える箇所。
- `[ペルソナ]` `[スナップショット]` = 保存済みの全文をそこに貼る、の意味。
- プロンプトはすべて日本語のまま使える。伊語成果物が欲しい場合も指示は日本語でよい(出力言語だけ指定する)。
