## 1. Uber Eats 出店の実務データ

### 手数料

| 形態 | 手数料(税別) | 備考 |
|------|------------|------|
| Uber配達員に配達を任せる | **35%**(税込実質38.5%) | 戦略の試算前提と一致 |
| 自店スタッフが配達 | **15%** | ランチ帯に配達余力があれば大幅改善 |
| 店頭受け取り(Uber経由テイクアウト) | **12%** | 柱Bのテイクアウトと導線を共有できる |

- 注文数に応じた割引(月3,000件未満30%等)を載せるまとめサイトもあり、**情報が揺れている**。
  契約時に正式な料率を必ず書面で確認すること。損益分析(タスク#15)は35%で保守的に試算しておけば安全。
- 売上は**週1回の週次入金**、振込手数料はUber負担。キャッシュフロー面では悪くない。

### 初期費用・固定費

- 通常5万円の初期登録料が**キャンペーンで0円**(2020年から継続中、終了時期未定)。
- 月額利用料・タブレットレンタル料・決済手数料・振込手数料は無料。
- → **初期投資はほぼ写真撮影と包材のみ。撤退してもサンクコストが小さい**ので、
  4週間テスト→判断という計画の進め方と相性が良い。

### 必要書類・審査

- **飲食店営業許可証**(有効期限内・登録住所と許可証住所が一致していること)
- 酒類をデリバリーで売る場合は**酒類小売業免許**が別途必要
  (→ 当面はランチの料理のみで開始し、酒類は載せないのが簡単)
- 審査期間は**最短1週間〜2ヶ月**と幅がある。写真・メニュー情報の完成度で変わる。
  → **申請(タスク#17)は前倒しした方がよい。**7/13期限のままだと稼働が8月にずれるリスクあり。
  申請自体はスマホから可能。

## 2. Instagram(Meta)広告の日本の相場

### ベンチマーク

| 指標 | 相場 | 戦略の設計値との整合 |
|------|------|--------------------|
| CPM(1,000表示あたり) | 500〜3,000円(ストーリーズは400〜1,200円) | — |
| CPC(1クリック) | 30〜200円 | — |
| CTR | 1〜2% | — |
| 検証しやすい日予算 | **1,000〜2,000円** | 計画どおり |
| 半径ターゲティング | **最小1km**から設定可 | 3〜5km設定は問題なく可能 |

- 立地別の推奨半径: 都市部繁華街2〜3km / 駅前3〜5km / 郊外5〜10km。
  → 配信設定時にうちの立地でどれに当たるか決める。

### テスト予算でどこまで見えるか(試算)

日予算1,500円 × 14日 = 21,000円 の場合:
- CPM 800円(ストーリーズ中心)なら約26,000表示
- CTR 1.5%なら約390クリック(実質CPC約54円)
- クリック→予約/来店の転換率を2〜5%とすると**予約・来店8〜20件、CPA 1,000〜2,600円**
- → **戦略の「予約CPA 2,000円以下でスケール」は相場的に現実的なライン。**
  転換率が読めないのが最大の不確実性なので、予約経路(リンク/DM/電話)を必ず記録すること。

  ②**梅雨明け前から猛暑の予想** → 「梅雨だけの対策にしない」という戦略方針は正しい。
  8月はデリバリー・テイクアウトが猛暑時の来店抑制の受け皿になる。

## 4. 雨の日集客の他店事例

- **降水確率連動型**: 汐留のホテルダイニングは「当日朝9時の降水確率30%以上でランチ20%オフ」。
  → 発動条件が機械的なので迷いがなく、告知もしやすい。
  **うちの雨の日セットも「朝9時の降水確率○%以上で発動」ルール化を推奨**(判断コストゼロになる)。
- **昼夜で内容を変える**: 市ヶ谷の中華店は昼=次回使える50円券(再来店誘導)、夜=ドリンク100円引き(即時値引き)。
  → 昼は「次につなげる」、夜は「今日の来店動機」と目的を分ける設計は参考になる。
- **見落としがちな取りこぼし**: 雨の日は「行き先を素早く決めたい」心理が強まるのに、
  営業時間・入口までの濡れない動線・テイクアウト可否などの**来店前情報が未整理なだけで負ける**。
  → Googleビジネスプロフィール更新(タスク#3)に「駅からの濡れにくい道順」を追記すること。

## 5. この調査を受けた計画への示唆

1. **タスク#17(Uber Eats出店申請)は審査が最長2ヶ月かかるため、できるだけ前倒し。**
   申請はスマホから可能なので、デスクトップ復帰を待つ必要なし。
2. 雨の日セット(タスク#1)に「朝9時降水確率○%以上で発動」の機械的ルールを入れる。
3. 損益分析(タスク#15)は手数料35%で保守的に。自店配達(15%)と店頭受け取り(12%)も
   選択肢として並べて試算する。
4. 酒類はデリバリーに載せない(酒類小売業免許が必要なため)。
5. IG広告は予約経路の記録体制(リンククリック/DM/電話の区別)を配信開始前に決める。
