# トラットリア 梅雨時売上回復戦略(2026年)

対象店舗: **Baker's Dozen(ベイカーズダズン)** 静岡県沼津市町方町 — 店舗プロフィールと商圏分析は
[bakersdozen-numazu-profile.md](./bakersdozen-numazu-profile.md) 参照
作成日: 2026-07-02 / 対象期間: 2026年7月〜8月(梅雨明け後の盛夏対策を含む)

## 1. 現状認識

- 梅雨入り以降、来店客数の減少により売上が落ち込んでいる。
- 雨天は「外出そのものの抑制」「駅から店までの導線の悪化」「予約キャンセル増」を引き起こす。
  つまり落ち込みの主因は **来店動機の低下** であり、料理やサービスの質の問題ではない。
- したがって打ち手は次の3方向に整理できる:
  1. **雨でも来る理由を作る**(来店動機の上乗せ)
  2. **来店に依存しない売上を作る**(テイクアウト・物販・B2B)
  3. **来た客の単価を上げる**(コース・ペアリング・季節限定)

> まず最初にやるべきことは **過去2年の6〜7月の売上データ棚卸し**(曜日別・天候別・客数/客単価分解)。
> 感覚ではなくベースラインを持ってから各施策の効果を測る。

## 2. 戦略の柱

### 柱A: 雨の日を「お得な日」に変える(即効・低コスト)

| 施策 | 内容 | 狙い |
|------|------|------|
| 雨の日セット | 本日のパスタ+グラスワインの限定セット | 雨天時の来店動機を直接作る |
| 雨の日おもてなし | 傘立て・傘袋・おしぼりタオルを入口に常備 | 「雨の日こそ行きたい店」の体験を作る |
| 雨の日クーポン | LINE公式/Instagramで当日午前に配信 | 天候連動で即日集客できる導線を持つ |
| Googleビジネスプロフィール更新 | 雨の日特典・写真・営業時間を最新化 | 「近くの店」検索での取りこぼし防止 |

- 雨の日特典は**「当日朝9時の降水確率が○%以上なら発動」の機械的ルール**にする
  (他店事例: 降水確率30%以上でランチ20%オフ)。毎朝の判断コストがゼロになり、告知文もテンプレ化できる。
- 雨の日は「行き先を素早く決めたい」心理が強まる。Googleプロフィールには
  **駅からの濡れにくい道順・入口の場所**まで書いておく(来店前情報の未整理は静かな失注要因)。

### 柱B: 来店に依存しない売上をつくる(構造対策)

- **テイクアウト**: 看板パスタ・前菜など3品に絞って開始。原価率と容器コストを先に計算(#genka)。
- **物販**: 自家製ソース・焼き菓子の店頭販売。**Baton(菓子工房)との連携**でシナジーを狙う。

#### B-2: ランチタイムの Uber Eats 展開(分析)

**現状(2026-07-03 オーナー確認)**: 出店申請・審査は完了済み。現在は**ディナーの非混雑時のみ解放**して稼働中。
**ランチ帯と併設菓子店(Baton)は導入済みだが未稼働**。

つまり審査リードタイムはゼロで、残る作業は「営業時間の解放設定」と「メニュー公開」だけ。

**6月実績(4週間)**: 5件・¥25,950・**客単価¥5,190**。分析は
[ue-dinner-baseline-2026-06.md](./ue-dinner-baseline-2026-06.md) 参照。
要点: 客単価はデリバリー相場の2〜3倍(2人前ごちそう需要)で1件あたりの採算は良い。
**課題は露出量**(0.2件/日、前半2週はゼロ件)。狭い営業時間窓はアルゴリズム上不利なため、
ランチ帯解放+Baton稼働で「開いている時間」を増やすことが最短の打ち手。
メニューは**ディナー=2人前セットで単価勝負、ランチ=一人前セットで件数勝負**と役割を分ける。

ランチ帯は厨房の稼働に余力があり、デリバリーの**限界費用が低い**時間帯。
またオフィス/在宅のランチ需要は店内ランチ客とほぼ競合しないため、純増分の売上になりうる。
ただし手数料が重いので、**ユニットエコノミクスを先に固めてから解放する**。

**Baton併設菓子店は隠れた本命**: 焼き菓子は配達30分での品質劣化がなく、雨天の影響も受けない。
在宅の午後のおやつ需要・手土産需要はランチともディナーとも競合しない完全な純増になる。
トラットリアのドルチェと組み合わせた「雨の日おやつセット」などのクロスセルも可能。

**1注文あたりの採算の考え方**(出店前にこの式で全メニューを検算する):

```
手取り     = デリバリー価格 × (1 − 手数料率35%想定)
貢献利益   = 手取り − 食材原価 − 包材費
```

試算例: 店内1,200円のパスタをデリバリー価格1,600円(店内比+33%)で出すと
手取り1,040円。食材原価360円+包材80円なら貢献利益600円/注文。
1日5注文で月間約9万円の粗利上乗せになる計算。

**設計上の要点**:

- **手数料の実勢**(2026-07調査、詳細は [research-2026-07-notes.md](./research-2026-07-notes.md)):
  Uber配達35%(税込実質38.5%)/**自店配達なら15%**/店頭受け取りなら12%。
  週次入金のためキャッシュフロー面も悪くない。
  ~~審査は最短1週間〜最長2ヶ月かかるため出店申請は前倒しする~~ → **申請済み・稼働中のため解消**。
  酒類のデリバリーは酒類小売業免許が必要なので当面載せない。
- **価格**: 店内価格をそのまま載せない。手数料分を上乗せした「デリバリー専用価格」(店内比+30〜40%が相場)。
- **メニュー**: 配達30分後でも品質が保てる品に限定(オイル系・ラグー系パスタ、冷菜、ドルチェ)。
  クリーム系・揚げ物など劣化が速い品は載せない。**出店前に30分放置テストを全品実施**。
- **オペレーション**: ランチピークと重なるため、同時受注上限・調理動線・受け渡し場所を先に決める。
  ホール品質を犠牲にしてまで受けない(受注一時停止を躊躇しない)。
- **プロモ**: 出店直後はUber内の露出が優遇される。初回割引などのプラットフォーム内プロモは
  この期間に集中投下してレビュー件数を稼ぐ(★4.5以上の維持が生命線)。
- **撤退基準を先に決める**: 開始4週間で「注文数×貢献利益」を評価し、
  月間貢献利益が包材在庫・手間に見合わなければ撤退または縮小。だらだら続けない。

### 柱C: 客単価アップと平日夜の埋め合わせ

- **季節限定コース**: 初夏野菜・鮎・白ワインペアリングなど「梅雨〜盛夏だから食べたいもの」を軸に開発(#signature)。
- **エンタメコース(12,000円)のB2B営業**: 既存プロジェクトを加速。企業の暑気払い・歓送迎需要はまさに7月が商機。ターゲット10社のリスト化から。
- **雨の夜イベント**: ワイン会・料理教室を月1で。雨天でも「予約済みの予定」はキャンセルされにくい。

### 柱D: リピート構造(中期)

- 常連向けサブスク/回数券の検討(キャッシュフロー先取り+来店頻度の固定化)。
- YouTube発信(既存領域)との連携で店のストーリーを継続発信。

### 柱E: Instagram広告への投資(少額テスト → 計測 → スケール)

オーガニック投稿だけではフォロワー外に届かない。広告(Meta広告経由のInstagram配信)は
飲食店と相性が良いが、**「いくら使うか」ではなく「1件の予約/来店をいくらで買えるか」で管理する**。

**配信設計**:

| 項目 | 設計 |
|------|------|
| ターゲティング | 店舗半径3〜5km、25〜54歳(商圏外に配信しない。これが飲食店広告の最重要設定) |
| 目的 | プロフィール誘導+予約リンク/Uber Eatsストアリンクへの誘導 |
| クリエイティブ | 料理のリール動画 vs 静止画の2種でA/Bテスト(リールの方がCPM効率が良い傾向) |
| テスト予算 | 日予算1,000〜2,000円 × 2週間(総額1.5〜3万円)。いきなり増額しない |
| 天候連動 | 雨予報日に日予算を引き上げる「雨の日ブースト」。柱Aのクーポン配信と連動させる |

**判断基準(テスト2週間後)**:

- 計測するもの: CPM、CTR、プロフィール訪問単価、フォロワー獲得単価、**予約1件あたりの獲得単価(CPA)**
- スケール条件の目安: 予約CPA ≦ 客単価 × 粗利率 × 想定リピート回数。
  例えば客単価6,000円・粗利60%なら、初回だけで3,600円までは理論上ペイする。
  リピートを見込めばCPA 2,000円以下なら明確に増額してよい。
- 効かなければクリエイティブを先に疑う(予算を増やす前に動画を差し替える)。

## 4. やらないことの明確化

- 値引き一辺倒の集客(ブランド毀損・利益率悪化)。
- ユニットエコノミクス検算なしのデリバリー本格展開(手数料35%前提の専用価格・4週間テスト・撤退基準をセットで運用する)。
- 計測なしの広告増額(CPAが取れていない状態で日予算を上げない。先にクリエイティブを差し替える)。
- 梅雨だけの一時しのぎ施策への過剰投資(8月の猛暑も来店抑制要因。**天候に強い売上構造**を作るのが本丸)。
