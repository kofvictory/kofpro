## ① v3で書き換えた所＝声に出すと段差が出やすい（最重点）

読み慣れた旧台本と違い、ここは**初めて声に乗せる**。通し読みで引っかかったら印をつける。

- [ ] **⑥E→⑦A の接続**（v3の最大の一手）
  「でも、ここで止めるつもりはありませんでした。NPU化はいったん“宿題”として切り離して——まずは、いま動くローカルとクラウドの切り替えを、**実用品として詰める**ことにした。」
  →（⑦A）「**ところが。**その“逃げ道”を作ったことで、今度は**別の問題**が起きました。**生きているローカルから、コフが勝手に逃げるんです。**——しかも、最初の1回だけ。」
  ✔ 「ところが。」で一拍。谷（⑥）から新バグ（⑦）へ**気持ちを切り替える段差**を声で作る。

- [ ] **⑦C 原則先出し**
  「原因は、シンプルでした。**『生きてるかの確認』と『答えを待つこと』を、同じタイマーで測ってた**んです。この2つは、別の時間軸。**死活確認は短く、処理待ちは長く**——そう分けるべきだった。」
  ✔ 「死活確認は短く、処理待ちは長く」は**この動画の一番の持ち帰り＝大テロップと同期**。ここだけゆっくり、一語ずつ置く。

- [ ] **② 三すくみ（圧縮）**：頂点①②③を早口で潰さない。「一日中いる相棒が…」「でも、軽い操作まで…」「かといって、手元の小さいモデルだけだと…」の**3つの制約に等間隔の"間"**。図の点灯と合わせる余白を残す。

- [ ] **⑤ ルーティング（圧縮）**：「分岐は3つだけ。」の後、pingの一言「**“生きてる?”って軽くpingで確認してから**」が早口で消えないように（⑦の伏線）。

- [ ] **⑥D 助走（乾かした版）**：「……そもそも、使っていないNPUを動かしたくて、この開発を始めました。でも、今の構成では、そこにまったく届いていなかった。」
  ✔ ここは**説明的に淡々と**。感情は次の決め台詞に集中させる（下 ④参照）。

- [ ] **⑧B 「繋ぎ→土台」**：「今回のハイブリッドは**使い捨ての“繋ぎ”じゃない**。NPU版の頭脳ができても、この土台はそのまま残る。」
  ✔ 自虐に聞こえないトーンで（設計を安売りしない）。

## ② 用語グロス＝“知らない体”で聞いて引っかからないか（品質ゲート）

初出で**直後に“つまり〜”の言い換え**が自然に入るか。エンジニアは満足・ライト層は追従、の両立。

- [ ] **フォールバック**（初出⑤D）→「“ダメなら別の手段に自動で切り替える”仕組み」
- [ ] **コールドロード**（初出⑦B）→「最初の一回だけ準備で待たされる」（“コールドスタート”に寄せてもOK）
- [ ] **ping**（⑤）→「生きてる?の軽い確認」
- [ ] **Function Calling / ツール**（①④）→「AIが自分で機能を呼ぶ」
- [ ] **正規化**（④）→「1つの共通の形に揃える」
- [ ] **ルーティング**（⑤）→「どっちを使うか振り分け」
- [ ] **ONNX / QNN / Hexagon**（⑥）→固有名詞。**ゆっくり1回ずつ**、意味は“NPU用の別ルート”で足りる

## ③ 数値＝ハッキリ発音（テロップと同期・品質ゲート）

早口・語尾埋もれで数字が消えると"持ち帰り"が死ぬ。**数字の前後で微かに区切る**。

- [ ] NPU **0%** ／ CPU **約69%（3.2GHz）**（⑥の核）
- [ ] ping **2.5秒** ／ 生成タイムアウト **240秒**（⑦の解）

## ④ 生命線＝間・トーン（ここは急がない／絶対変えない）

- [ ] **⑥D 決め台詞**「**いちばんやりたかったことが、いちばん遠かった。**」→ **直後に無音を一拍キープ**。感情の底。複数テイク推奨。
- [ ] **③ テーゼ一文**「コフの“らしさ”は、モデルの中じゃなく、外側の設計に置いた。」→ **間を取ってから言い切る**（切り抜き・引用の核）。
- [ ] **③ メタファー**（役者＝モデル／役・脚本＝人格）を**最後まで一本で通す**（言い換えない）。
- [ ] **②E 結論**「全部を一度に満たす脳は、無い。」→ 一拍置いて言い切る。
- [ ] **⑨ ボタン**（最後はコフに渡す）「——それじゃ、続きは次回。…次こそ、ちゃんとNPUで動いてみせるよ。」→ ナレで締めず、**コフの一言で終わる**。湿っぽくしすぎない。

**章別トーン早見**（[音]指示ベース）:
⓪⑴OP夢=静かな憧れ / ①=軽快・朝 / ②=納得・静かに論理 / ③=気づき・腑に落とす / ④=手が動く歯切れ / ⑤=整理された締め / **⑥=谷・テンポ落とす** / **⑦=山・テンポ戻す・解決の快感** / ⑧=満足→正直→前向き / ⑨=落ち着いて3つ・最後コフ

## ⑤ 録りの実務メモ

- [ ] **章ごとに録る**（通しでなく）。NGは章内の該当ブロックだけ録り直し＝編集で差し替え。
- [ ] **マイク距離・室内の静けさを固定**（章跨ぎで音質が変わらないように）。冷蔵庫/空調のハム確認。
- [ ] **⑥D と ⑨ボタンは複数テイク**（感情モノは後で選べるように）。
- [ ] **②⑤の圧縮部は"やや遅め"を意識**（詰めた分、早口になりやすい）。
- [ ] 収録前に**喉ウォームアップ＋水分**。⑥の谷は声を"落とす"演技なので喉に余裕がある状態で。
