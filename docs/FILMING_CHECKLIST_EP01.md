# EP01 撮影前チェックリスト（受け入れ基準の確認手順）

> BUILD_SPEC_FOR_EP01 の必須4項目を、撮影マシン（Snapdragon X / Windows 11）で
> 本番前に検証するための手順書。各項目 **2〜3回連続で再現** できたらチェック。

## 事前セットアップ

```powershell
git pull
npm install
npm run electron:dev
```

- `.env.local` に `ANTHROPIC_API_KEY` があること（⑤フォールバック/賢いモードに必須）
- `ollama list` に `qwen2.5` があること
- **テイク前のウォームアップ**: コフに捨てメッセージを1つ送って応答させておく
  （モデルがメモリに載り、以後の応答が速くなる。約5分アイドルで再びコールドに戻る）

## 1. Markdown生表示が出ない

- [ ] 「今日やることを教えて」→ 返答に `**` `|` `#` `-` の羅列が出ない
- [ ] 「inboxに何があるか教えて」→ 表のダンプでなく話し言葉で返る
- [ ] 賢いモードON で同じ2問 → 同様に生記法が出ない

> 出た場合: そのテイクは捨てて言い回しを変えて再送（小型モデルは稀に漏れる。
> 賢いモード(Claude)はほぼ確実に守る）。

## 2. 実演操作の安定（ビート①B / ⑤ / ⑥ / ⑦）

### クイックキャプチャ → inbox → コフが拾う
- [ ] メイン上部の入力欄に「来週の登壇資料つくる」→ 追加 → Inboxに即表示
- [ ] コフに「inboxに何がある？」→ 今追加したものを答える

### 今日やること（today_view）
- [ ] 事前仕込み: コフに「『◯◯』を今日締切のタスクとして追加して、着手中にして」
- [ ] 「今日やること見せて」→ 仕込んだタスクが返る

### 完了(done)更新
- [ ] 「◯◯は終わったよ、完了にして」→ コフが完了報告
- [ ] メインの「着手中」/「今日」一覧から消える（フローティングから操作しても
      メイン一覧が自動更新される＝ウィンドウ間同期）

### ⚠️ オフライン実演の罠（重要）
- [ ] 機内モードON → コフに**雑談**（「おはよう、今日も頼むね」等）→ ローカルで応答する
- **タスク操作はオフラインでは失敗する**（SupabaseがクラウドDBのため）。
  ①B終盤の「ネット切っても動く」カットは**会話のみ**で撮ること。
  タスク一覧・追加・完了はオンラインで撮る。

### フォールバック（⑤の主役カット）
- [ ] Ollama を完全終了。**必ず親(監視役)から先に殺す**こと:
      ```powershell
      taskkill /F /IM "ollama app.exe"   # 先: トレイの監視アプリ
      taskkill /F /IM ollama.exe         # 後: サーバー本体
      ```
      （タスクトレイの Ollama 右クリック → Quit でも両方止まる）
      ⚠️ `ollama.exe` だけ殺すと監視役が**即座に自動再起動**してフォールバックしない（実機で確認済みの罠）
- [ ] 死活確認: `ollama list` が**接続エラーになる**こと（これが出れば失敗テイクなし）
- [ ] コフに話しかける → 約2.5秒のping失敗後、自動でClaudeが応答。
      返答バブル下のチップが「ローカル」(灰)→「**Claude**」(琥珀)に変わるのが画で分かる
- [ ] Ollama を再起動（スタートメニューからOllama起動）→ 話しかける → チップが「ローカル」に戻る

### コールドロード（⑦の実測用）
- [ ] `ollama stop qwen2.5` でモデルだけをメモリから降ろす（サーバーは生存）
- [ ] コフに話しかける → **誤フォールバックせず**、十数秒待ってローカルが応答
      （ping成功→生成に時間がかかる、が二段タイムアウトの見せ場。ストップウォッチで実測）

## 3. 賢いモードの別人感（ビート①C / ③E / ⑤）

- [ ] チャットヘッダーの「🧠 賢い」をタップ → ヘッダーが**紫→琥珀**に変わり、
      表示が「ローカル (Ollama)」→「**賢い (Claude)**」に切り替わる（ワンタップ・即時）
- [ ] 同じ質問を両モードで:
      推奨: 「inboxを見て、どれから手をつけるべきか相談したい」
      - 通常: 簡潔な1〜2文
      - 賢い: 実データを踏まえた根拠つきの踏み込んだ提案（能動提案）
- [ ] 返答チップも 灰「ローカル」/ 琥珀「Claude」で区別できる

## 4. フローティング常駐（OP / ①A / 全編）

- [ ] アプリ起動 → 画面右下に**コフ本体だけ**が出る（白い小窓なし・背景透過）。
      画面端で見切れず、作業領域内に収まっている
- [ ] メインを**最小化** → コフは残る（他アプリを全画面にしても最前面に居る）
- [ ] **コフをクリック** → 縁なしの吹き出し（チャット）が浮かんで開く。× or 再クリックで閉じる
- [ ] **コフ自体を掴んでドラッグ** → そのまま移動できる（4px以上動かすとドラッグ、
      動かさず離すとクリック判定）。吹き出しのヘッダーを掴んでも移動できる
- [ ] 画面外へ放り投げても作業領域内へスナップバックする
- [ ] 上記を3回繰り返しても位置・サイズ・開閉が破綻しない

> メモ: メインウィンドウを完全に閉じてもコフは残る（アプリ終了はコフを
> クリックしてフォーカス後 Alt+F4、またはメインを閉じる前にアプリ終了）。
> Electron起動時、メインウィンドウ内の右下アバターは自動で非表示（コフは
> フローティング側の1体だけ）。ブラウザで `npm run dev` を見る場合は従来どおり
> ページ内にアバターが出る。
> 万一この機種で透過ウィンドウが乱れる場合は electron/main.ts の
> `FLOAT_TRANSPARENT = false` で非透過カードに即戻せる。

## （任意）インボックスのキュレーション

撮影前にクイックキャプチャで整えると⑧の縦糸が画面に乗る:

- 「ローカル推論のパフォーマンス調査（npurunが有効かも）」 ← ⑧NPU縦糸・必須級
- 「動画作り企画出し」
- 「イタリア語の複合過去を復習」 ← 生活感カード（本物のライフログの証拠）
- 無関係すぎる古いカードは 見送り/保留 で整理

## 撮影小ネタ

- 応答チップ(ローカル/Claude)はズームで抜くと⑤の「切り替わった」が一目で伝わる
- 生成中の NPU 0% + CPU 使用率のタスクマネージャーは**ローカル応答中**に録る
  （賢いモード中はCPUも動かないので絵にならない）
