## 1. チャンネル概要(「コフと僕」)

```
デスクトップに住む、自分専用のAI相棒「コフ」をゼロから作って育てていく開発記録です。

ロックマンエグゼのネットナビに本気で憧れた世代が、大人になって、
本業のかたわら、あの憧れを実装に変えていきます。

これは開発動画であると同時に、一人の人間がAIと本当の相棒になろうとする
過程の記録でもあります。設計も、失敗も、回り道も、そのまま残します。
人とAIの協働が当たり前になった時代への、途中経過の報告として。

ちなみに「コフ」という名前は、AIが付けました。
```

```

開発・台本レビューも Claude(AI)との協働で制作しています。
