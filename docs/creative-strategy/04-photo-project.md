# 04. 写真プロジェクトひな型 — 企画・制作・コンペ・発表

## 前提: 2つのプロジェクトの性格の違い

| プロジェクト | 性格 | 時間軸 | 成功の定義 |
|---|---|---|---|
| 地球の記憶 | 生涯プロジェクト(『プロジェクト・ヘイル・メアリー』着想。人類と非人類知性の双方に向けた地球の記録) | 数十年 | 続いていること・深まっていること |
| 自転車シリーズ | コンペ向けシリーズ | 1〜3年 | IPA・Nikkor 等での入選/入賞 |

この2つは**同じ指標で管理しない**。地球の記憶に締切やKPIを課すと壊れる。ロードマップ(05)に載せるのは撮影行の回数と自転車シリーズ・コンペの進捗のみ。

---

## ひな型1: コンセプトの深化壁打ち(地球の記憶用)

成果物を出させるのではなく、考えを深めるための対話プロンプト。

```
[ペルソナ]

あなたは写真評論家であり、科学と哲学に通じた対話相手です。
生涯プロジェクト「地球の記憶」について壁打ちをしたい。

## プロジェクトの現在の言語化
- 着想: 『プロジェクト・ヘイル・メアリー』。人類だけでなく、非人類の知性(未来のAI・地球外知性・人類後の存在)にも読める地球の記録を残す
- 現在の被写体: {{直近で撮っているもの}}
- 今考えていること: {{断片的でOK}}

## 進め方
- 一度に結論を出さず、1つずつ問いを investigate する対話形式で
- 私の考えを言い換えて確認してから、次の問いを出すこと
- 必要なら仏教哲学(天台・日蓮系)・物理学・言語学のアナロジーを持ち込んでよい

## 最初に扱いたい問い
{{例: 「非人類知性に読める写真」とは、何が写っていれば成立するのか / 記録と作品の境界はどこか}}

## 最後に
対話の到達点を、プロジェクトステートメントの改訂案(400字)として言語化してください。
```

## ひな型2: シリーズの撮影計画(自転車シリーズ・新シリーズ共通)

```
[ペルソナ]
[スナップショット]

シリーズ「{{名前}}」の撮影計画を作ってください。

- コンセプト: {{1〜3行}}
- 現在の手持ち: {{点数と、強いカットの傾向}}
- 目標: {{例: IPA {{年}}のシリーズ部門に8点で応募}}
- 撮影に行ける頻度: 月{{N}}回(定休日ベース)、遠出は{{...}}
- 機材: Nikon Zfc(主)/ Sony RX100 M4(副・携行用)

## 出力形式
1. 足りないカットの分析(現在の手持ちに対して: 画角の偏り / 光の種類 / 距離感 / 季節)
2. 撮影地×季節×時間帯のマトリクス(沼津・伊豆・箱根・富士宮・駿河湾沿岸を軸に、各回の狙いを1つに絞る)
3. 直近3回分の撮影行プラン(場所 / 集合外出時間 / 狙うカット / 撮れなかった場合の代替)
4. 各撮影行を YouTube ③シネマティックエッセイの素材と兼ねる場合の追加準備(音声・動画クリップ・三脚)

## 条件
- 「良い写真を撮る」ではなく「シリーズに欠けている1枚を埋める」計画にすること
```

## ひな型3: コンペ戦略(IPA・Nikkor ほか)

```
[ペルソナ]
[スナップショット]

写真コンペへの応募戦略を作ってください。

- 応募候補: IPA(International Photography Awards)/ ニッコールフォトコンテスト / {{他に検討中のもの}}
- 手持ちのシリーズ: 自転車シリーズ({{点数・傾向}})/ 地球の記憶からの単発候補({{...}})
- 過去の応募歴: {{あれば結果も}}

## 依頼
1. 各コンペの性格の違い(審査傾向・カテゴリ構成・応募費・締切)を整理し、私の作品との相性を評価
   ※最新の締切・要項は変わるので「公式で確認すべき項目リスト」も添えること
2. 12ヶ月の応募カレンダー(締切から逆算した セレクト→プリント/現像調整→応募 の作業配置)
3. カテゴリ選択の推奨(同じ作品でも入りやすいカテゴリの考え方)
4. 選外だった作品の再利用ルート(別コンペ・SNS・プリント販売)

## 条件
- 応募費の年間予算 {{N}}円以内に収めること
```

## ひな型4: セレクトとシーケンスの講評(応募・発表前)

```
あなたは国際コンペの審査経験がある写真キュレーターです。
シリーズ「{{名前}}」のセレクトを講評してください。

コンセプト: {{ステートメント下書きを貼る}}
構成: 以下の順に{{N}}点。各写真を1行で説明します(または画像を添付します)。
1. {{何が写っているか・光・距離}}
2. {{...}}

## 講評の観点
1. シリーズとしての一貫性(視覚言語が揃っているか)
2. 最も強い1枚と最も弱い1枚、その理由
3. 並び順(シーケンス)の改善案 — 1枚目と最後の1枚の選定理由つき
4. 「足りない1枚」は何か(次の撮影行の狙いになる)
5. コンセプト文と写真の間のズレ(言葉が写真を説明しすぎ/写真が言葉に届いていない箇所)

## 条件
- 賞賛より改善点を優先。ただし直すべきでない長所も1つ明示すること
```

## ひな型5: ステートメント執筆(展示・応募用)

```
シリーズ「{{名前}}」のステートメントを書いてください。

- プロジェクト概要: {{...}}
- 制作の動機: {{...}}
- 見る人に感じてほしいこと: {{...}}
- 使ってほしいキーワード / 避けたい表現: {{...}}

## 出力形式(4点セット)
1. 日本語 200字(コンペ応募用・簡潔)
2. 日本語 400字(展示・Web用)
3. 英語版(200字版の翻訳ではなく、英語圏の審査員向けに書き直したもの)
4. イタリア語版(SNS・伊語圏向け)

## 条件
- 飾った抽象語(「心の琴線」「唯一無二」等)を使わない。具体的な事物と行為で書く
- 骨子(何を言い、何を言わないか)を先に提示し、合意後に4点を書いてください
```

## ひな型6: 発表ロードマップ(コンペの外へ)

```
[ペルソナ]
[スナップショット]

シリーズ「{{名前}}」の発表計画を、コンペ応募以外も含めて設計してください。

## 検討したい選択肢
- Web(ポートフォリオサイト / SNS連載)
- zine・フォトブック(少部数)
- 展示: 貸しギャラリー / 公募展 / **店(ベイカーズダズン)の店内ギャラリー化**(常設展示+プリント即売。店長権限で決められる範囲かの確認込み)
- YouTube ③シネマティックエッセイでの映像化

## 依頼
1. 各選択肢の 費用 / 工数 / 届く相手 / 売上・次につながる度合い の比較表
2. 推奨の順序(例: Web→コンペ→店内展示→zine)とその理由
3. 店内ギャラリー案の具体化: 展示替え頻度 / プリント・額装の外注先の選び方 / 価格帯 / 店の雰囲気と喧嘩しない掛け方 / 店長として通す場合の合意形成(誰の承認が要るか)
4. 各発表をチャンネル②③・Instagram へ還流させる導線
```

## ひな型7: 撮影行→エッセイ回の二毛作設計(③との連携)

```
次の撮影行を、写真とYouTube ③シネマティックエッセイの両方の素材収集として設計してください。

- 行き先: {{例: 松崎町}} / 日程: {{定休日1日}}
- 写真側の狙い: {{シリーズ名と欲しいカット}}
- 動画側の狙い: {{エッセイのテーマ。台本があれば貼る}}

## 依頼
1. 1日のタイムテーブル(光の時間帯を写真優先で確保し、動画クリップは移動・待ち時間に割り当てる)
2. 動画に必要な最低限のショットリスト(引き/寄り/移動/環境音)と、写真撮影と両立できない瞬間の優先判断ルール
3. 機材リスト(Zfc・RX100 M4 の役割分担、音声、三脚の要否)
4. 帰宅後の素材整理手順(写真セレクトと動画素材のビン分けを1回で済ませる方法)
```

---

## 運用メモ

- 地球の記憶は**成果を求めない枠**として週次レビュー(05)の「続いているか」だけを見る。撮れ高ゼロの撮影行も成功と数える。
- コンペは締切駆動。締切をロードマップのマイルストーンに直接置く(ひな型3の応募カレンダーを 05 のクール計画に転記)。
- プリント販売・店内展示はマネタイズ(03)のひな型2「商品ラダー」の中価格帯として扱う。
