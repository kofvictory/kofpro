## 2. この公開情報から戦略に効くこと

### ① 「パティシエのイタリア食堂」はデリバリー/広告で最強の差別化軸

- 沼津のランチイタリアン競合(パスタ屋一丁目、DADA、マリーノ、Bivi内店舗など)は
  ¥970〜1,600の価格帯で生パスタ・漁港直送などを訴求。
  **「パティシエが作るドルチェまで完結する食堂」は誰とも被らない**。
- Baton焼き菓子・ドルチェをUber Eatsとテイクアウトに載せることは、
  単なる商品追加ではなく**この差別化軸をデリバリー面に展開する**こと。
- IG広告のクリエイティブも「パスタ+ドルチェ」のセット画で撮ると独自性が出る。

### ② IGフォロワー約4,300人は広告の起爆剤になる

- ゼロからの広告ではなく、**エンゲージメント済みオーディエンス**(投稿に反応した人)や
  その類似オーディエンスを配信対象にできる。CPAはコールドスタートより下がりやすい。
- 雨の日クーポンのオーガニック告知だけでも4,300人にリーチできる。
  広告はその増幅装置として設計する。

### ③ 沼津のUber Eats環境は「先行者の少ない地方都市型」

- 沼津のUEは2021年3月開始(初日75店舗)。都市部ほど飽和していない。
- **配達エリアは沼津市街地+清水町・三島市の一部**。
  → 店の徒歩商圏(駅8分)を超えて、**三島方面の需要まで届く=商圏拡大装置**。
- 沼津の他店事例では**売上の約25%がUber Eats**という取材記事あり。
  現状(月約¥26,000)との差が、そのまま伸びしろ。
- 市内は出前館・楽天ぐるなびデリバリーも利用可能だが、加盟店数と使いやすさでUEが最有力。

### ④ 商圏の性格

- 沼津市の人口は約18〜19万人(減少傾向)。人口増に頼れない商圏なので、
  戦略の方向(客単価アップ・商圏拡大・リピート構造・天候耐性)は沼津の実情に合っている。
- 駅徒歩8分・商店街立地 → IG広告の半径ターゲティングは**3〜5km**(駅前立地の目安)で
  沼津中心市街地+近郊をカバーできる。
- 港町・観光導線(沼津港)もあるが、梅雨期は観光客も減るため、
  当面は地元客+デリバリーの足元需要を優先するのが妥当。

### ⑤ KAIZUKAのデリバリー適性は要検証

貝のスープ仕立てはデリバリー30分での品質維持が難しい可能性(スープの吸い込み・貝の硬化)。
- 案A: スープとパスタを分離容器にして「2人前KAIZUKAセット」を看板にする(単価¥5,000超の実測と合う)
- 案B: KAIZUKAは店内限定の「来店理由」として残し、デリバリーはラグー/オイル系を看板にする
→ 30分放置テスト(タスク#16)で決める。
