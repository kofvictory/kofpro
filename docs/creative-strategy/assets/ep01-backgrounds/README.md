各章の**全画面16:9背景**（テロップ・図解・ナレの下地）。10章を **4ムード** に集約して再利用する（1ベース系→変奏）。
真実源は [`ep01-backgrounds.json`](ep01-backgrounds.json)。IPセーフ（抽象のみ・エグゼ/PET/キャラ意匠は不使用）。

- 形式: **1920×1080 PNG**（`*.png` がCapCutに敷く本番／`*.html` が再レンダリング用ソース）
- 配色: ep01-figures と同一トークン（ダーク紫地＋ラベンダーグリッド＋navi teal `#5fd6c0`＋warm `#ffcf8a`）
- 可読性: 中央〜下1/3を沈めてある＝**テロップはそのまま乗る**

## CapCut 運用

1. 背景PNGを**最背面レイヤー**に全画面で配置。
2. **寄り/パン(Ken Burns)** をごく緩く（例: 3〜6%スケール移動を章尺いっぱいで）＝静止画に生命感。
3. 図解・テロップ・スクリーン録画はこの上に重ねる。
4. 章が切り替わる所で背景も差し替え（同ムード連続章は続けて敷いてOK）。

## タイトルアイキャッチ（⓪→①の橋）

「コールドオープン→夢パートへの暗転にタイトルを差す」提案の**タイトルカード**。⓪の緊張(0%)から①夢パートへの落差を暗転＋タイトルでクッションしつつ「掴んでから名乗る」。

| ファイル | 役割 | 背景 |
|---|---|---|
| `title-eyecatch-cold` | **入口**：0%の緊張の残像を引きずった冷たい立ち上げ | deep-tense（冷・淡クリムゾン） |
| `title-eyecatch-warm` | **到達点**：夢の温度＝①へ渡すメイン | dream-bookend（暖） |

- 文字：タイトル＝**明朝 Noto Serif JP**（物語側）／標「EP.01 ◇ コフと僕」＝ゴシック（情報側）。サムネB主案(明朝)と世界観一致。
- **0%数字はここに出さない**（⓪とサムネの役目／カードは"広いエモ"側）。

### CapCut 運用（尺1.5〜2.5秒・動きの中で）

```
⓪コールドオープン(0%) →暗転0.3〜0.5s→ [cold] →クロスフェード0.5〜1s→ [warm] →①夢パート
```

1. cold→warm のクロスフェードで「冷→暖」＝**0%の緊張を断ち切らずタイトルの温度へ転じる**橋を作る。
2. 文字は**立ち上げ＋軽ズーム**（静止させない）。静止した長いタイトル画面は15秒圏の離脱点。
3. **BGMは切らない**＋タイトル出でSE一発（夢寄りの柔らかい発光音／シャキーン系は避ける）。"無音→一音"は③接続専用に温存。
4. 簡略版：**warm 1枚だけでも成立**（cold は冷→暖を編集で作りたい時に使う）。
