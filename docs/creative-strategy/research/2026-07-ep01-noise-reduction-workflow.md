# EP01 ノイズ除去ワークフロー（空調あり収録・2026-07-20調査）

> **前提**: 猛暑によりエアコンON収録。機材=DJI Mic Mini 2（RX→USB-C→PC）+ Audacity 3.7.5+（ARM64ネイティブ）。
> **大原則**: エアコンノイズは**「録りで減らす→残りを後処理で消す」の2段構え**。
> 後処理は魔法ではない——録音時のS/N比（声とノイズの差）を最大化するほど、後処理が軽く済み声質が残る。

---

## 1. 録音時の空調対策（後処理の負荷を半減させる）

- [ ] **エアコンは風量弱/静音モード**に。ルーバー（風向き）は**マイクと逆方向**へ。風が体・マイクに直接当たらない位置で録る
- [ ] **マイクと口の距離を詰める（10cm前後・正面から少し斜め）** ← 一番安いノイズ対策。
  距離が半分になると声は約+6dB、エアコン音は変わらない＝S/N比が丸ごと改善
- [ ] TXの背面をエアコン側に向ける（マイク正面をノイズ源に向けない）
- [ ] **収録中はエアコン設定を変えない**（風量が変わるとノイズフロアが変わり、①プロファイルが合わなくなる ②章間の音の連続性が壊れる）
- [ ] **ルームトーン15秒を必ず録る**（エアコンONの本番と同じ状態で。休憩後に設定を触ったら録り直す）
  → ノイズ除去のプロファイル用 ＋ 編集で無音を埋めるパッチ用の二役
- [ ] DJIノイキャンは**まずOFFで試し録り** → 下のパイプラインで消えるか確認 → 消え残るなら「基本」で比較テイク1本（強はVO非推奨・声が痩せる）

## 2. Audacity 後処理パイプライン（順序が命）

**Step 0. 原本保護**: 録音ファイルは必ず複製してから加工（`raw/` と `edit/` を分ける）

**Step 1. プロファイル取得**
ルームトーン部分を選択 → エフェクト → ノイズ除去と修復 → **ノイズの低減** → 「**ノイズプロファイルを取得**」

**Step 2. ノイズ低減（本体）**
全体（or 章単位）を選択 → 同メニュー → 設定値:

| パラメータ | 開始値 | 調整レンジ | メモ |
|---|---|---|---|
| ノイズ低減(dB) | **12** | 6〜18 | エアコンなら12→足りなければ15,18。**24以上は禁止圏**（声が水中音化） |
| 感度 | **6** | 5〜8 | 上げるほど多くの音をノイズ扱い。声が削れたら下げる |
| 周波数平滑化(バンド) | **3** | 3〜6 | 上げるとなめらか・ぼやける。VOは3で十分 |

⚠️ **強く1回より、控えめ2回**（例: 12dB×2パス）の方がアーティファクトが少ない。

**Step 3. ハイパスフィルター（低域カット）**
エフェクト → EQとフィルター → ハイパスフィルター（または Filter Curve EQ）で **80〜100Hz以下をカット**（ロールオフ 12〜24dB/oct）。
エアコンの「ゴォー」成分は50〜120Hzに集中、男声の基音はおおむね100Hz以上なので声はほぼ無傷。こもりも取れて一石二鳥。

**Step 4. 耳チェック（ヘッドホン必須）**
判定ポイントは**語尾と無音部**。「シュワシュワ」「金属的な残響」「水中っぽさ」が出たら **Step2の低減量を下げる**（感度を下げるのも効く）。
自然なノイズがうっすら残る > 声が加工臭くなる、が正解。

**Step 5.（任意）整音**
軽いコンプレッサー → **ラウドネスノーマライズでナレ単体を -16〜-14 LUFS**（Audacity: エフェクト→音量と圧縮→ラウドネスの正規化）。
※最終の**-14 LUFSは動画全体（BGM込み）の書き出し時**にCapCut側で確認する話。ナレ単体はここで揃えておくとCapCutでの音量合わせが楽。

**Step 6. 書き出し**
章ごとに WAV（48kHz/24bit）でエクスポート → CapCutへ。

## 3. 事故時のエスカレーション（3段構え）

1. **Audacity NR（上記）** — まずこれ。プロファイル式は定常ノイズ（エアコン）に最も強い
2. **DJI NC「基本」テイク** — 録音時比較用に1章ぶん確保しておく（後処理で消えない場合の乗り換え先）
3. **Adobe Podcast Enhance v2** — 最後の手段。**強度スライダーを30〜50%に落として**使う（100%は"AI声"化する）。全編にかけず、**ダメな章だけ**。無料枠に上限があるので本当に必要な分のみ

## 4. 明日のテスト手順（10分）

1. エアコンONの本番状態で **⓪コールドオープンを試し録り**（30秒）＋**ルームトーン15秒**
2. 上記パイプライン（Step1〜4）を一回通す
3. ヘッドホンで **処理前後を聴き比べ**: ①エアコン音は消えたか ②語尾がシュワついてないか ③声の太さが残ってるか
4. **OK → そのまま本番へ**（テスト設定値をメモして全章同じ値で）／ **NG → DJI NC「基本」で再テスト** → それでもダメなら風量・距離・配置を見直し

## 5. 判定の目安

- 録音波形の無音部が **-50dB以下** … 十分静か。NR軽め(6-9dB)でOK
- **-45〜-40dB** … エアコン相応。標準パイプライン(12dB)で問題なし
- **-35dB以上** … ノイズ過多。後処理より先に**距離・配置・風量を見直す**（後処理で無理に消すと声が死ぬ）
  ※Audacityの表示で確認: 選択→解析→測定 or 波形のdB表示切替

## 6. 接続トラブルシュート（RXがAudacityに出ない時）

**大原則: RXの電源状態で"何として認識されるか"が変わる**（DJI公式）:
- RX **電源OFF**でPC接続 → **USBドライブ**（ストレージ）＝マイクとして出ない
- RX **電源ON**でPC接続 → **オーディオ機器**（マイク）＝Audacityに出る

切り分け（上から）:
1. **RXを電源ONにして挿し直す**（自動電源オフでスリープしてないか）。エクスプローラーにリムーバブルディスクが出たら＝RXがOFFだった証拠
2. Audacity **Transport→オーディオデバイスの再スキャン**（起動後に挿すと出ない）。効かなければ再起動
3. 入力ドロップダウンで「DJI MIC MINI」選択（汎用名 "USB Audio Device" のことも）。ホストを MME⇄WASAPI 切替
4. **データ対応USB-Cケーブル**（充電専用が紛れる）・**別ポート直挿し**（ハブ回避）
5. Windows 設定→サウンド→入力に居るか＝Audacity側(2-3)か物理層(4)かの分岐。マイクのプライバシー許可も確認
> **実績（2026-07-22 / 07-26 の2回とも）**: 「認識せず」は **#1（RX電源ON＋挿し直し）で復旧**。毎セッション再発する。
> **予防（恒久）**: ①**「RX電源ON確認→挿す」を毎回の儀式に**（挿してからONではなく、ONにしてから挿す）。②DJI Mimoアプリで**自動電源オフをオフ/延長**にすると寝なくなり再発しない。③RXを充電しておく（低電池もスリープ誘発）。
