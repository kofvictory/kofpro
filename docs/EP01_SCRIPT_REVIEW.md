## 課題（重大度順）

### 🔴 ⑤ビートD 「ヘッダー色が紫→オレンジに変わる」は実機で起きない
実装ではヘッダー色はトグル(smartMode)連動。自動フォールバックではトグルは動かず
**ヘッダーは紫のまま**。変わるのは**応答元チップ(灰ローカル→琥珀Claude)**のみ。
既撮影のフォールバックテイクもチップが変化・ヘッダーは紫のはず。
→ 採用方針: **(A) 台本をチップ基準に修正**(コード変更ゼロ・既撮影と一致)。下記差分1。

### 🟡 ⑥ビートC 図解「(環境によっては Vulkan/GPU)」が撮影素材と矛盾して見える
撮影マシン実測(DEVLOG): `ollama ps`=100% CPU / GPU 12%は描画由来。純CPU。
画面GPUが動いていると「GPU使ってる」と誤読されうる。
→ 採用方針: **この動画では純CPUと言い切る**(「この構成では」限定は残す)。下記差分2。

### 🟡 ② 「日本語が崩れる」弱点カットの素材変更
stripMarkdown導入でMarkdown崩れは画面に出ない。弱点は実録の造語(「manentbox」)や
実在しないタスクの捏造(『レポート作成』等)クリップで見せる。下記差分3(演出メモ追記)。

### 🟡 ⑦ コールドロード実測値【●●秒】未確定 → 収録・編集前に測って埋める。

### 🟢 OP尺2:20(master_rundown既知。16:15ならOK。15分狙いならOP→1:50)。
### 🟢 ④「10個近く」実際は11個(現状の表現でも可)。

## 章をまたぐ影響
- 🔴⑤Dの修正は①C・③Eに波及しない(あちらはトグル=ヘッダー色で正しい)。
  「トグル時=ヘッダー色 / フォールバック時=チップ」と分けると③テーゼ「頭脳交代」を
  2通りの画で実証でき伏線が厚くなる。
- ②の弱点素材を造語クリップにすると、⑤(フォールバックの必要性)・⑥(小型ローカルの限界)と

- 伏線マップ(NPU0%→⑥→⑧ / ①別人感→③ / ⑤ping→⑦ / OLLAMA_HOST→⑧)は全て健在。
