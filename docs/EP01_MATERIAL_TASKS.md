# EP01 動画素材タスク — コフ登録用

> shot_list.md の素材を、コフ(create_entry)に渡せる粒度へ再構成したもの。
> 「まとめ撮り」原則で1タスク=1作業セッション。制作順は B証拠 → A録画 → Cコード → D図解 → E/F/G/H。
>
> **使い方**: 下の「バッチ1〜4」を1ブロックずつコフにコピペする。
> **🧠賢いモード推奨**（ローカル小型モデルは複数タスクの一括作成が不安定。
> 1リクエストのツール呼び出し上限があるため4〜5件ずつに分割してある）。
>
> 💡 登録後に「今日撮る素材タスクを全部着手中にして」と頼むと today_view に載り、
> ①Bの実演「今日やること見せて」で**本物の撮影予定が画面に映る**（一石二鳥）。

---

## バッチ1 — 証拠キャプチャB（最優先・撮り直せない）

```
次の動画素材タスクをまとめて登録して。すべて種別はtask、領域はyoutubeで。
1. 「生成中のNPU 0%とCPU使用率をタスクマネージャーで録画する（OP/⑥/⑧/⑨で4回使う主役証拠）」優先度urgent、稼働量quick、期限は今日
2. 「コールドロードの実時間を計測して録画する（ollama stop qwen2.5で再現、⑦の数値テロップの根拠）」優先度urgent、稼働量quick、期限は今日
3. 「スペック画面でNPUの文字が見えるキャプチャを撮る（OP用）」優先度high、稼働量quick、期限は今日
4. 「推論速度tok/sのキャプチャを撮る（⑥⑦用・任意）」優先度low、稼働量quick
```

## バッチ2 — 画面録画A・前半（同一セッションでまとめ撮り）

```
次の動画素材タスクをまとめて登録して。すべて種別はtask、領域はyoutubeで。
1. 「コフが常駐している構図を録画する（作業画面の横に居る画、OP/①/⑨）」優先度high、稼働量quick、期限は今日
2. 「実演一連を録画する（クイックキャプチャ→今日やること見せて→これ終わった、①B）」優先度high、稼働量short、期限は今日
3. 「オフライン応答を録画する（機内モードで雑談のみ。タスク操作は撮らない、①②⑤）」優先度high、稼働量quick、期限は今日
4. 「賢いモードOFF→ONの別人感を同条件で録画する（同じ質問を両モードに、①⑤）」優先度urgent、稼働量quick、期限は今日
```

## バッチ3 — 画面録画A・後半 + コード差分C

```
次の動画素材タスクをまとめて登録して。すべて種別はtask、領域はyoutubeで。
1. 「Ollamaを落として自動フォールバックの瞬間を録画する（⑤の主役カット。応答元チップが灰→琥珀に変わる画）」優先度urgent、稼働量quick、期限は今日
2. 「誤フォールバックのビフォーアフターを録画する（修正前コミットで再現→修正後はローカル維持、⑦）」優先度high、稼働量short
3. 「ローカルモデルの日本語が崩れる瞬間を一瞬だけ撮る（②の弱点提示用）」優先度medium、稼働量quick
4. 「コード差分を2点キャプチャする（ツール定義の変換関数、ping/生成の二段タイムアウト分離。差分のみ全文NG、④⑦）」優先度medium、稼働量quick
```

## バッチ4 — 後工程（図解D・モーションE・テロップF・ナレG・音H）

```
次の動画素材タスクをまとめて登録して。すべて種別はtask、領域はyoutubeで。
1. 「図解一式を制作する（三すくみ三角形・2層レイヤー図・翻訳レイヤー図・/api/agentフローチャート・二段タイムアウト図。③の頭脳差し替えアニメは⑧で流用前提）」優先度medium、稼働量deep
2. 「コフのモーションをポスト編集で付ける（待機・メッセージ反応・うなずきの3種のみ）」優先度medium、稼働量deep
3. 「テロップ素材一式を統一装飾で制作する（テーゼ引用・数値2.5s/120s/0%・Vulkan赤訂正線など）」優先度medium、稼働量short
4. 「ナレーションをマスター進行台本の順で一括収録する（⑨コフの一言は口調3テイク）」優先度medium、稼働量deep
5. 「BGMとSEを選定する（⑥の谷はBGMを抜いて無音→一音）」優先度low、稼働量short
```

## 制作順の依存関係（shot_list の要点）

数値(バッチ1) → 図解(バッチ4-1) → ナレの数値読み(バッチ4-4) の順を守ると手戻りしない。
バッチ2と3の録画は、ネット切断・モデル落とし・モード切替を**同一セッションで連続**して撮ると状態管理が楽。
