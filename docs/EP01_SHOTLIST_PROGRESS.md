> 🟡2本は本人判断で撮り直し確定 → このセッションで消化する。

**撮影順（通常設定 → env var変更 の順で、環境いじりは最後にまとめる）**

1. **クイックキャプチャ**（実タスク入りでリアルに）— ①

3. **⑤ON→Claude / 通常→ローカル**（チップ色でバックエンドが分かる）— ⑤

5. **🔁撮り直し: 別人感 OFF→ON**（お題分担: OFF=「今日やること見せて」/ ON=相談系）— ①/⑤
6. **⑥⑧成果ダイジェスト短クリップ** — ⑥/⑧
7. **オフライン応答**（⚠️会話のみ・タスク操作は不可）— ⑦(実演の罠回避)
