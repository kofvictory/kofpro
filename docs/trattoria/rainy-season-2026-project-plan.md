## 運用リズム

- **毎週月曜**: 週次レビュー(タスク#14として登録済み)。
  1. 先週の売上・KPIを戦略ドキュメントの表と突き合わせる
  2. `/triage` の inbox を空にする(着手/見送り/保留)
  3. `/active` を見て今週の due_at を設定 → `/today` が毎朝の実行リストになる
- 見送り(declined)にした施策も理由を残す(triage_decisions に自動記録される)。
  梅雨明け後・来年の梅雨前に判断履歴を見直せるようにするため。
