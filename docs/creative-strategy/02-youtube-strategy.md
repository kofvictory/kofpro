# 02. YouTube戦略ひな型 — 3ライン体制の設計と毎週の制作

## 前提: 3つのコンテンツライン

| ライン | 言語/視聴者 | 現状 | 実務ドキュメント |
|---|---|---|---|
| ① コフ開発シリーズ | 日本語 / 個人開発・エンジニア層 | EP01 制作中 | `claude/desktop-ai-agent-avatar-*` ブランチの `docs/` |
| ② 日本式リヴィジタツィオーネ料理 | イタリア語 / 料理・日本文化好き | 台本あり・未開設 | (未作成) |
| ③ 知られざる日本シネマティックエッセイ | イタリア語 / 旅・映像好き | 松崎町の台本あり・未撮影 | (未作成) |

このファイルは3ライン横断の**ひな型**置き場。①の個別の制作実務(EP01の撮影・編集・公開)は avatar ブランチ側が正。

---

## ひな型1: ライン優先順位の意思決定(最初に1回、以後クールごと)

3本同時は時間的に不可能、という前提を最初に固めるためのプロンプト。

```
[ペルソナ]
[スナップショット]

YouTube のコンテンツラインが3つあります(コフ開発 / 伊語料理 / 伊語エッセイ)。
週{{N}}時間の制約下で、今後6ヶ月のリソース配分を決めてください。

## 判断基準(この順で重み付け)
1. 既存資産の再利用度(店の厨房・撮影地・書き上げた台本・アプリ実装)
2. 1本あたりの制作コスト(撮影・編集時間)
3. マネタイズまでの距離(視聴者層×収益手段の相性)
4. 私が続けたくなるか(生涯プロジェクトとの整合)

## 出力形式
1. 各ラインの評価表(上の4基準×5点満点、根拠つき)
2. 推奨配分(例: 主力1・保守1・凍結1)と、その配分にする理由
3. 凍結するラインの「凍結条件と再開条件」(捨てるのではなく棚上げの設計)
4. 主力ラインの直近4本の投稿ペース案

## 条件
- まず、判断に必要な質問があれば先にしてください(最大5つ)
- 「全部少しずつ」という配分は禁止。傾斜をつけること
```

## ひな型2: チャンネルコンセプト設計(②③の開設前に)

```
[ペルソナ]
[スナップショット]

チャンネル「{{②リヴィジタツィオーネ料理 / ③シネマティックエッセイ}}」のコンセプトを固めてください。

## 埋めたいフレーム
- 誰に: {{例: イタリア在住で日本料理・日本文化に関心がある20-40代}}
- 何を: {{例: イタリア料理を日本の技法・食材で再解釈する過程}}
- なぜ私が: 現役パティシエ+トラットリア経営者 / 日本在住 / イタリア語話者 — この3点の交差は他に誰がいるか

## 出力形式
1. コンセプト文 3案(それぞれ切り口を変える。各: 一言コンセプト+説明100字+想定される競合チャンネルとの違い)
2. 各案のチャンネル名案 3つ(伊語。発音しやすさと検索性を考慮)
3. 概要欄の自己紹介文(伊語100語+日本語訳)
4. 推奨案と理由、最初の3本に何を置くべきか

## 条件
- 骨子(1のコンセプト3案)を先に出し、私が選んでから 2〜4 を書いてください
```

## ひな型3: コンテンツピラー+企画30本

```
[ペルソナ]
[スナップショット]

チャンネル「{{ライン名}}」の企画ストックを作ってください。
コンセプト: {{一言で}}
反応が良かった/手応えのある既存ネタ: {{あれば。無ければ「まだ無い」}}

## ステップ1: コンテンツピラー
柱を3〜4本設計してください。各柱: 名前 / 視聴者がそれを見る瞬間 / 流入経路(検索・ブラウジング・ファン化)。

## ステップ2: 企画30本(表)
| # | 仮タイトル(32字以内) | 柱 | フォーマット | 狙い(検索/関連/ファン化) | 制作コスト(S/M/L) |
- 検索:関連:ファン化 = 5:3:2 の比率で
- 私の既存資産(店の厨房・仕込み・沼津/伊豆の撮影地・開発中のアプリ)で撮れるものを優先
- S コスト企画を最低10本含める(繁忙期用)

## ステップ3: 推薦
最初に作るべき3本と、その順序の理由。
```

## ひな型4: 1本の企画ブリーフ(制作前の設計図)

```
次の動画1本の企画書を作ってください。

チャンネル: {{ライン名}}
仮タイトル: {{...}}
言いたいこと(1文): {{...}}
視聴者が持ち帰るもの: {{...}}

## 企画書の項目
1. タイトル案 5つ(32字以内、数字か具体語を入れる)
2. サムネイル文言案 3つ(13字以内)+ 画のイメージ(何をどう写すか)
3. 冒頭15秒のフック台本(離脱させない理由を作る)
4. 本編の構成(章立て、各章の要点、想定尺、山と谷の位置)
5. 締めとCTA(次に見せる動画/登録導線)
6. 撮影・編集のTODOリストと想定作業時間(私の週{{N}}時間に収まるか判定つき)

## 条件
- 伊語チャンネルの場合: タイトル・サムネ文言は伊語+日本語訳の併記で
- 4の構成までを先に出し、合意後に3のフック台本を書いてください
```

## ひな型5: バイリンガル台本の3段フロー(②③用)

イタリア語動画は「構成は日本語で詰める → 伊語で書く → ネイティブ視点で直す」の3往復に分ける。

```
【1往復目: 構成】
[企画ブリーフ(ひな型4の出力)を貼る]
この構成を、ナレーション台本の設計図(章ごとの要点・トーン・映像指示)に展開してください。まだ本文は書かないでください。

【2往復目: 執筆】
合意した設計図に沿って、イタリア語のナレーション全文を書いてください。
条件: 話し言葉 / 1文は短く / 専門用語(料理・日本文化)は初出で一言説明 / 各段落に対応する日本語要約を併記。

【3往復目: 自然さレビュー】
このイタリア語台本を、ネイティブ視聴者として読み直してください。
指摘対象: 直訳調 / 硬すぎる語彙 / 文化的に通じない比喩。修正案は差分ではなく修正後の全文で。
```

## ひな型6: タイトル・サムネの当て直し(公開前の最終確認)

```
公開前の最終チェックです。この動画のタイトルとサムネ文言を磨いてください。

動画の内容(3行): {{...}}
現在の候補: タイトル「{{...}}」/ サムネ文言「{{...}}」
チャンネルの過去タイトル: {{あれば列挙。トーンを揃えるため}}

## 依頼
1. タイトル10案(数字入り/疑問形/断言形/ベネフィット形を混ぜる。32字以内)
2. サムネ文言5案(13字以内。タイトルと同じ言葉を使わない=情報の重複を避ける)
3. 各案がどんな視聴者心理を突くかの一言解説
4. あなたのベスト組み合わせ(タイトル×サムネ)と理由
```

## ひな型7: アナリティクス診断(公開後・月次)

```
YouTube アナリティクスの数字を貼ります。診断と次の一手をください。

チャンネル: {{ライン名}} / 期間: {{直近28日}}
- インプレッション: {{}} / CTR: {{}}%
- 平均視聴維持率: {{}}%(平均視聴時間 {{}})
- 視聴回数: {{}} / 登録者増減: {{}}
- 上位動画とトラフィックソース: {{貼り付け}}

## 依頼
1. ボトルネックの特定(露出→クリック→維持→回遊→登録 のどこで詰まっているか)
2. その判断の根拠(数字の読み方の説明つき。基準値との比較)
3. 次の4本で試す改善アクション(1本につき1つに絞る)
4. 「数字が悪くても変えなくてよい点」も明示(方針がブレるのを防ぐ)
```

## ひな型8: シリーズ設計(縦糸×横糸)

コフ開発シリーズで使っている「縦糸(シリーズを貫く物語)×横糸(各回の持ち帰り)」構造を他ラインにも展開する。

```
[ペルソナ]
[スナップショット]

チャンネル「{{ライン名}}」を単発動画の集合ではなくシリーズとして設計してください。

## フレーム
- 縦糸: シリーズ全体で進行する物語({{例: 一皿のイタリア料理が日本の食材で生まれ変わっていく / 伊豆半島を一周する}})
- 横糸: 各回それだけ見ても成立する持ち帰り(レシピ/絶景/知識)

## 出力形式
1. 縦糸の候補 3案(それぞれ: 何話くらい続くか / 最終回のゴール / 途中参加の視聴者への配慮)
2. 推奨案で EP01〜EP06 の仮タイトルと各回の横糸
3. 「シリーズを追う理由」を作る仕掛け(次回予告・進捗の見える化など)3つ
```

## 運用メモ

- **バッチ制作**: 撮影は定休日に2〜3本分まとめ、編集は営業日の朝に分割する前提でひな型4の工数を見積もらせる。
- **二毛作**: 写真プロジェクトの撮影行(伊豆・松崎など)は③のエッセイ回と兼ねる。→ [04-photo-project.md](04-photo-project.md) の連携ひな型を参照。
- **①の実務**: EP01 の編集・公開・収益化チェックリストは avatar ブランチの `docs/EP01_POST_UPLOAD_MONETIZATION.md` が正。ここのひな型7はその後の運用フェーズで使う。
