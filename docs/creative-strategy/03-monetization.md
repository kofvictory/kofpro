# 03. マネタイズ戦略ひな型 — 収益源の選定から90日計画まで

## 前提: 資産と収益候補のマップ

店(ベイカーズダズン/Baton)の売上戦略は `claude/trattoria-sales-strategy-*` ブランチが正。ここでは**創作活動由来の収益**を扱う。
ただし「創作→店への送客」は相乗効果として常に選択肢に含める。

| 既存資産 | つながる収益候補 |
|---|---|
| 料理・製菓の腕 + 店の厨房 | 伊語圏向けレシピ電子書籍 / 料理講座 / 店への送客(インバウンド) |
| 写真作品(地球の記憶・自転車) | プリント販売 / コンペ入賞→単価向上 / ストックフォト / フードフォト受注 |
| イタリア語 + 多言語 | 伊語圏チャンネルの広告・Patreon / 翻訳つき商品 |
| 開発力(React/Supabase) | コフ開発シリーズの広告・企業案件(開発ツール系)/ アプリ自体の将来的な製品化 |
| 店という場所 | 店内ギャラリー(写真展示・プリント即売)/ ワークショップ会場 |

## ひな型1: 収益源の評価と選定(クールごとに見直し)

```
[ペルソナ]
[スナップショット]

私に合う収益源を選定してください。

## 候補(必要なら追加・削除して)
YouTube広告(3ライン別に評価) / メンバーシップ・Patreon / 企業案件 / アフィリエイト(撮影機材・開発ガジェット) /
レシピ電子書籍(伊語) / Lightroomプリセット・LUT販売 / プリント(作品)販売 / ストックフォト /
フードフォト受注(沼津の飲食店向け) / 料理・写真ワークショップ / 店への送客(伊語圏インバウンド)

## 依頼
1. 各候補を評価する表: 収益上限 / 立ち上げ工数 / 実現確度 / 私の資産との相性(各5点満点+一言根拠)
2. 上位3つについて、最初の90日でやることを週単位で
3. 「今はやらない」候補とその理由(切り捨てではなく、着手条件を添えて)
4. 収益源同士の相乗効果マップ(例: YouTube→電子書籍への導線、コンペ入賞→プリント単価)

## 条件
- 飲食店経営の繁忙と両立できる工数か、を必ず評価に入れること
- 在庫・発送作業が発生するものは、その負荷も明記すること
- まず不明点を質問してから(最大5つ)評価に入ること
```

## ひな型5: 90日マネタイズ計画(ひな型1の結果を受けて)

```

## 出力形式
1. 90日後の状態目標(収益額ではなく「仕組みが動いている状態」で定義。例: 商品1つ公開済み・導線設置済み)

## 条件
- 総作業時間は週{{N}}時間の5割以内(残りは制作本体に使うため)

- 骨子を先に提示し、合意後に週次表を書いてください
```

## ひな型6: 事務・制度の確認リサーチ(判断の前提を固める)

```
本業に創作収益を追加するにあたり、確認すべき事項を整理してください。
私の状況: 沼津市のトラットリアで店長を務める(報酬の形態: {{給与 / 役員報酬 / 事業所得 — 自分の形態を記入}}) /
創作収益は YouTube広告・デジタル商品販売・プリント販売を想定 / 伊語圏(EU)向け販売も視野

## 依頼
1. 税務: 私の報酬形態を前提に、創作収益の所得区分(雑所得/事業所得)・帳簿の分け方・確定申告の要否ラインについて「税理士に確認すべき質問リスト」を作る(回答の断定はしない)
2. YouTube収益化: パートナープログラムの現行要件と、私の各ラインでの到達見込み
3. EU圏向けデジタル販売: VAT等、販売プラットフォーム側が代行してくれる範囲の整理
4. 写真販売: 人物・建築物が写る作品の権利面で注意すべき一般的な論点
それぞれ「今すぐ確認」「収益発生後でよい」に分類してください。
```

## 運用メモ

- 収益の遅行性: 広告収益は登録者・再生の**遅行指標**。ロードマップ(05)では先行指標(公開本数・商品公開数・提案数)で計画を立てる。
- 最初の90日は「稼ぐ」より「**課金導線が存在する状態**」を作るのが目標。金額目標は2クール目から。
- 月次レビュー(05)のたびに [スナップショット] の収益欄を更新し、ひな型1の評価表を再実行すると、判断の変化が記録として残る。
