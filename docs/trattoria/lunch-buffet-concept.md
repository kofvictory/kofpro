# 構想: ランチ・ビュッフェスタイルの試運転(来年に向けて)

作成: 2026-07-15。オーナー構想:
「都心のイタリアンで流行りのビュッフェスタイルを来年のランチ形態として試運転したい。
単価2,000〜3,000円、焼きたてのパン・カットピザ・一品料理を店員が回って提供する形。
人件費と工数の削減も兼ねる。」

## 1. なぜ Baker's Dozen と相性が良いか

**"パティシエの営むイタリア食堂" という差別化軸が、そのままビュッフェの主役になる。**
焼きたてパン・カットピザ・ドルチェの食べ放題は、沼津の競合ランチ(¥970〜1,600の生パスタ系)
とは土俵が違う。店名の由来(baker's dozen=パンのおまけ)とも一致し、
「パン屋の血を引く店の、焼きたて食べ放題ランチ」という強い物語になる。

現ランチ帯(¥1,000-1,999)から**客単価¥2,000〜3,000へ引き上げる**打ち手でもあり、
戦略の柱C(客単価アップ)に直結する。

## 2. 「人件費・工数削減」— 正直な効き方

期待は妥当だが、**効く所と、逆に増える所がある**ので設計で舵を取る。

**工数が減る所(本命は厨房)**
- アラカルトの多品目・個別盛り付け・オーダー取り・伝票管理が消える。
- **固定メニューのバッチ製造**(パンを焼く・ピザを大判で焼く・一品を大量調理)は、
  もともとパティシエのオーブン稼働と相性が良い。ここが最大の工数削減。
- 回転が上がり、席あたりの売上効率(seat-hour)が改善しやすい。

**逆に増える/減らない所(ホール)**
- 「店員が回って提供する」方式は、**常に誰かが回り続ける**ぶんホール人件費が単純には減らない。
- 料理の補充・温度/衛生管理・食べ放題の時間管理という新しい手間が生まれる。
- → **純粋なセルフ式ビュッフェほどは人件費が下がらない**点は見込んでおく。

**結論**: 「回って提供」は人件費を最小化する方式ではなく、**人件費↔食材ロスのバランスを取る方式**。
削減の本丸は厨房の工数と回転率。ホールは"減る"より"読めるようになる"効果が大きい
(→ 自動化②の売上連動シフトと好相性)。

## 3. 最大のリスクは食材ロス。ただし「回って提供」がむしろ効く

ビュッフェの弱点は食材ロス(原価率の悪化)。だが今回の方式はここで有利に働く:
- **店員が回ってポーションを渡す=取り放題より廃棄を制御できる**。セルフの盛りすぎ・食べ残しを抑制。
- 予約制+人数上限で仕込み量を確定(廃棄の主因=作りすぎを潰す)。
- 焼きたてパンは時間で回し、余りは翌日のテイクアウト/フードロス対策に転用。
- 時間制(例: 90分)で回転と提供量をコントロール。

つまり**「回って提供」は、人件費を少し払ってロスと単価を取りに行く**設計と読むと筋が通る。

## 4. 試運転(試運転)の設計案

いきなり毎日やらない。**限定条件でテストして数字を取る**。

- **頻度**: まず週1日、または閑散曜日のランチのみ(例: 火 or 水)。
- **予約制・席数上限**: 仕込み量を確定し、ロスと人員を読めるようにする。
- **価格**: ¥2,480 など¥2,000〜3,000の中で1点。ドルチェ食べ放題を含むかで¥2,000台/¥3,000弱を出し分け。
- **メニュー**: 焼きたてパン数種+大判カットピザ+一品料理3〜4種+サラダ。ドルチェは強みなので目玉に。
  KAIZUKA等のシグネチャーは「+¥○○の単品追加」で残し、来店理由を両立。
- **期間**: 1〜2ヶ月回してから来年の本格導入可否を判断。

## 5. 測る指標(通常ランチとの比較で判断)

| 指標 | 通常ランチ(比較対象) | ビュッフェ試運転・目標 |
|------|--------------------|----------------------|
| 客単価 | 現状¥1,500前後 | ¥2,000〜3,000 |
| 原価率 | 店平均 | +数%以内に抑える(ロス管理) |
| 席あたり回転 | 現状 | 上げる(時間制) |
| ランチの人件費/売上 | 現状 | 横ばい〜微減で単価増を取る |
| 満足度/再来店 | — | アンケート・リピート率 |

**原価率と人件費率が許容内で、客単価と回転が上がれば成功**。数字は試運転で確定させる。

## 6. 他の取り組みとのつながり

- **自動化①(売上データ)**: 固定メニューのビュッフェは売上・客数が読みやすく、需要予測の精度が上がる。
- **自動化②(シフト提案)**: 必要人数が安定するため、売上連動シフトと最も相性が良い形態。
- **柱C(客単価アップ)/季節限定コース**: ランチ単価の底上げと重なる。
- **夏祭りメモ**: 昼ランチのみ営業の日は、ビュッフェが回転・省人の面で有力な選択肢になりうる。

## 7. 次の一歩(来年の梅雨明け前に判断)

1. 試運転の曜日・価格・メニュー・席数上限を1案に固める
2. 90分制・予約制など運用ルールを決める
3. 1日だけ試験実施 → 原価率・人件費・客単価・満足度を記録
4. 通常ランチと比較し、来年の本格導入可否を決める
